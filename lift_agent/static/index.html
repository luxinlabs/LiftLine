Routing Trace (Audit Log)

Every automated lookup passes through Jev first. Jev returns a typed Choice naming the one data source allowed to answer that question, with a calibrated confidence. Below is the actual decision recorded for each call, in order.

How Jev Decides

  1. Agent needs a fact (e.g. "which car is machine 1002?").
  2. Only the question and the source catalog go to Jev. No PINs, phone numbers or names are sent.
  3. Jev returns a typed choice plus a probability for every source.
  4. Policy accepts it only if confidence is 80%+, it is the top pick, and it matches the source that owns that data. Otherwise a human dispatcher takes over.
  5. Only then is that one database queried, and the decision is logged.
